# AURA Engine – Real-Time AI Micro-Friction & Accessibility Simulator

## Overview
AURA Engine is an AI-powered accessibility assistant designed to detect micro-frictions and environmental hazards for visually impaired individuals in real time.

## Tech Stack
* **Language:** Python 3.10+
* **Computer Vision:** OpenCV, YOLOv8/v11
* **AI/ML:** Azure AI Vision, PyTorch
* **Hardware Target:** Edge Microcontrollers / Raspberry Pi

## Key Features
* Real-time spatial obstacle detection
* Micro-friction risk index calculation
* Low-latency auditory prompt generation
